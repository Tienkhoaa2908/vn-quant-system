# Validation archive

Bootstrap tự động gom bằng chứng kiểm định vào workstation:

- `source_snapshots/`: bản copy code và test V27, V41, V43 và V43.1.
- `artifacts/`: ZIP V42 VN100 capacity và V43.1 micro-capital mới nhất.
- `archive_manifest.json`: đường dẫn, thời gian archive và SHA-256.

Dữ liệu và ZIP lớn không commit lên Git nhưng tồn tại trong đúng thư mục hệ thống local để kiểm định lại.
